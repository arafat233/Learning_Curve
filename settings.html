Privacy Policy

    
Local data: profiles, resumes, job descriptions, STAR stories, session logs, pins, prep packs, reports, settings, and window state are stored in the app userData folder.

Cloud use: API answer generation, company research, prep packs, post reports, story matching, and coding workspace features can send relevant prompts, screenshots, profile context, or session text to the configured model provider. Local HTTP model mode sends text prompts to your configured local text endpoint and screenshots to your configured local vision endpoint.

Local-only mode: local transcription is forced and API cloud model calls are blocked while API backend is selected.

Telemetry: disabled by default. When enabled with an endpoint, only product event metadata is sent, such as feature name, app version, latency, token counts, character counts, selected practice track, and selected language. Interview transcript text, answers, screenshots, resumes, job descriptions, and STAR stories are not sent as telemetry payloads.

Deletion: Delete user data removes local profiles, session history, pinned answers, prep packs, reports, and saved context.
